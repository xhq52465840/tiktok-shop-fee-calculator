为什么要嵌入

  • 完全免费，不用注册账号，也不需要 API 密钥。
  • 费率在我们这边更新，你页面上的计算器始终是最新的。
  • 自适应布局：手机上单栏，宽屏上双栏。脚本版会自动调整高度。
  • 计算在访客的浏览器里完成，输入的数字不会发给我们或你，计算器也不设置任何 Cookie。

常见问题

嵌入后会拖慢我的页面吗？

脚本不到 2 KB，计算器采用懒加载，只有滚动到可见位置时才加载，之后由浏览器缓存。

可以调整尺寸吗？

计算器会占满所在容器的宽度，想小一点就放进更窄的栏里。使用纯 iframe 版时，请自行设置 height 属性（约 1,900 像素即可容纳所有计算器）。

数据会一直保持最新吗？

会。嵌入的计算器和我们计算器页面使用同一套费率表，平台调整费用后，你网站上的版本也会同步更新。
