Amazon FBM 预付退货标签新规（2026年12月18日起）：7 天期限与“退货 vs 仅退款”保本计算器

2026年12月18日起，自发货（FBM）的 Amazon 美国站卖家须在 7 天内上传预付退货标签，否则 Amazon 可能自动给买家退款。新规要点，以及“退货再卖”与“仅退款不退货”的保本计算器。

自 2026年12月18日起，Amazon 将要求几乎所有美国站自发货（FBM）订单的退货都使用预付退货标签。只给买家退货地址、让买家自付运费的做法将不再合规。本文解读这项变化，并提供一个计算器，帮你逐单判断是付费让买家寄回，还是直接退款不退货。

Amazon 通过发给卖家的邮件宣布了这项变化，PPC Land 和 Seller Essentials 均有报道。我们没有找到公开的 Amazon 官方页面：Seller Central 帮助页需要登录，而且据 PPC Land 报道，其 2026年10月19日查看的帮助页尚未提及此变化。请以你 Seller Central 账户中的通知为准。

2026年12月18日起有哪些变化

  • 美国站所有自发货订单的退货都需要预付退货运单。只写地址、由买家自行寄回并付运费的标签不再算数。
  • 重货和大件商品暂时豁免。Amazon 称这是临时安排，既没有定义该类别，也没有给出结束日期。
  • 每个退货申请发起后 7 个自然日内，你必须在 Manage Seller-Fulfilled Returns 中针对该申请上传预付标签，或者全额退款且不要求买家退回商品。
  • 如果两者都没做，Amazon 可能自动发起仅退款，并从你的卖家账户扣款，商品留在买家手里。
  • 通过 Buyer-Seller Messaging 或 Manage Returns 流程以外的其他渠道发送的标签不算数。

亚马逊物流（FBA）订单不受影响。Amazon 已通过 Buy Shipping 把美国卖家自动纳入预付退货；新规取消的是剩下的“仅地址”方式。标签费最终由谁承担仍可能取决于退货原因，请查看 Amazon 对卖家责任退货和买家无理由退货的处理方式。

退货还是仅退款？保本计算器

收到退货申请时，无论哪种方式你都要给买家退款。问题在于：把商品拿回来，值不值得付标签费、处理费和再次销售的成本。

退货再卖。商品拿回来的价值高于标签费和处理成本。请在 7 天内到 Manage Seller-Fulfilled Returns 上传预付标签。

仅退款不退货。把商品拿回来的成本高于它的价值。直接全额退款，不要求退货。

两种方式都要全额退款，所以退款本身不计入。示例数值仅供参考，请填入你自己的标签费和费率。

计算示例

假设标签费 $8、处理成本 $2、平台费率 15%、再次发货运费 $5、可再售概率 80%，一件 $25 的商品值得退回：预期收益 $3.00。保本再售价格是 $20.59，低于这个价格，仅退款更划算。同样的商品如果售价 $12，付费退回平均会亏 $5.84，应直接仅退款。

公式：预期收益 = 再售概率 ×（再售价格 ×（1 − 平台费率）− 发给下一位买家的运费）− 标签费 − 处理成本。

别让截止期限替你做决定

对便宜商品主动选择仅退款，是合理的经营决定；但如果是因为 7 天内没人上传标签而被 Amazon 自动仅退款，你可能连货带单一起损失。每天检查未处理的退货申请，指定负责人和备岗，并设定一个价格线，低于该价格团队可直接仅退款。

12月18日前的检查清单

  • 找出仍在使用“仅地址”标签或通过消息发送标签的商品和流程。
  • 确保每张标签都在 Manage Seller-Fulfilled Returns 中上传。
  • 用上面的计算器算出每个商品的保本再售价格。
  • 确认 Amazon 如何归类你认为属于重货和大件的商品。
