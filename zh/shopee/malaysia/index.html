    Shopee 马来西亚费用怎么算

    本地成交订单通常扣除：类目佣金、交易手续费、平台支持费。佣金取决于类目、Marketplace / Mall、是否加入返现计划（SCP）。我们加载的佣金百分比为含 SST（官方表 × 1.08），与 Shopee 例题把 9.0% 写成 9.72% 的口径一致。

    1. 佣金

    佣金 =（售价 − 卖家折扣）× 类目费率。平台出资券不减基数。Marketplace 与 Mall 使用不同费率表，SCP 卖家走更低的一列。自 2026年8月14日 起 Marketplace / Mall 表再次更新。

    2. 交易手续费

    买家实付金额（含运费）的 3.78%（含 SST），四舍五入到分，在成交订单上自动扣除。

    3. 平台支持费

    每笔成交 RM0.54（含 SST），与订单金额无关。

    4. 新卖家佣金豁免

    自 2026年8月1日起，Marketplace 佣金在「首件上架满 120 天」或「成交超 200 单」较早者之后才开始收取。可用计算器上的「新卖家」开关模拟豁免期。

    如何守住利润率

    • 对照 8月14日费率表重新定价。SCP 与非 SCP 两列是分别调整的；许多 Marketplace 非 SCP 费率并未改变，但 SCP 列往往有变化。请用计算器的两个开关核对主销 SKU。
    • 低单价商品尽量合并发单。平台支持费 RM0.54 按订单收取，不按件数。
    • 确认你是 Mall 还是 Marketplace。多数类目的 Mall 佣金比 Marketplace 高出数个百分点。
    • 若与卖家中心不一致，请直接改费率。类目归类可能与公开表不同；计算器里的每项费率都可以按你的账户修改。

    常见问题

    Shopee 马来西亚向本地卖家收哪些费用？

    类目佣金（Marketplace 或 Mall，SCP 或非 SCP）、按买家实付（含运费）计的 3.78% 交易手续费，以及每笔成交 RM0.54 平台支持费。部分计划或预售还可能有其他费用。

    佣金费率含 SST 吗？

    Shopee 公布的是尚未加 8% SST 的表列费率。本计算器存储的是含 SST 费率（表列 × 1.08），与 Shopee 官方例题口径一致（例如 9.0% → 9.72%）。

    2026年8月的佣金调整何时生效？

    Marketplace 与 Mall 新表均自 2026年8月14日 00:00 起生效。此前订单按旧列计。部分类目的非 SCP 列在此次调整中没有变化。

    谁能享受新卖家佣金豁免？

    自 2026年8月1日起，Marketplace 佣金在首件上架超过 120 天或成交超过 200 单（以较早者为准）之后才开始收取。

    SCP 是什么？

    加入 Shopee 返现计划（Cashback Programme）的卖家可走更低的 SCP 佣金列。资格与是否另收服务费，请以卖家中心为准。

    Shopee 马来西亚交易手续费是多少？

    含 SST 后为 3.78%，按买家实付（含运费）计。

    平台支持费是多少？

    每笔成交 RM0.54（含 SST）。
